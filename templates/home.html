About This Project

This application demonstrates Facial Expression Recognition using computer vision and deep learning. It uses OpenCV for face detection (Haar Cascade) and a Convolutional Neural Network (CNN) trained on the FER-2013 dataset to classify facial expressions into seven emotion categories: Angry, Disgust, Fear, Happy, Neutral, Sad, and Surprise.
